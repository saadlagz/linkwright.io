Linkwright free beta

While Linkwright for Jira is in Atlassian Marketplace review, the same app is available as a free beta, installed from a private link. It is the same code as the Marketplace version, under the name Linkwright Beta.

Install Linkwright Beta on your Jira site — no sign-up, nothing to pay. If GitHub for Atlassian already reads your repositories, read the first point of Before you install first.

Installed it? A one-line note to support@linkwright.io with your Jira site lets me check in and fix anything that gets in your way within 48 hours.

What you get

  • GitHub branches, commits, pull requests, reviews and deployments on your Jira issues, in Jira’s native Development panel — JQL, boards and Automation see them like any other development data.
  • For every repository, a sync state you can trust: Up to date, Out of date, Rate limited, Failing or Not authorized, with the time of the last webhook and of the last successful read, and a Refresh button.
  • Repositories attached per Jira project: a repository only links issues of the projects it is attached to.
  • Direct support from the developer, and a fix within 48 hours for anything that gets in your way.

Free until six months after the Marketplace release.

Install in three steps (about five minutes)

You need to be a Jira administrator, and an owner of the GitHub organization (or the personal account) that holds the repositories.

1. Install the beta in Jira

Open the installation link (also at linkwright.io/install-beta), choose your Jira site, then Install. The first screen can take up to 20 seconds while the app prepares its database; it says so while it waits.

2. Connect GitHub

  1. Install the Linkwright for Jira GitHub App on your organization and choose the repositories it may read.
  2. In Jira: Settings → Apps → Git sync health → Connect a GitHub organization, allow access to GitHub, then Connect to this site next to your organization.

A Get started checklist on that page shows what is done and what is left.

3. Attach repositories to a project

In the project: Project settings → Apps → Git repositories. Repositories whose recent commits already cite the project’s key are listed first as Suggested; Attach the suggested repositories attaches them all. Each one turns Up to date within seconds.

Push a commit whose message starts with an issue key (ABC-12 fix login): it reaches the issue in a few seconds. On a brand-new Jira site, Jira’s own Development panel can take a few minutes to show the first data; the app’s Git activity panel (apps button under the issue title) shows it at once.

The full guide is in the documentation.

Before you install: three things to know

  • Do not run two GitHub connectors on the same repositories. If GitHub for Atlassian already reads a repository, remove it from that app’s GitHub installation first, or try the beta on other repositories. Two connectors on one repository take links away from each other in Jira (we measured it on 1 October 2026).
  • Moving to the Marketplace version later means installing that version and attaching the repositories again — a few minutes. Your Git history is read again; nothing is lost on GitHub.
  • GitHub.com only for now; no GitLab or GitHub Enterprise Server yet. The other limits are listed in the documentation.

Your data

The app runs on Atlassian Forge: what it stores (repository names, commit and pull request metadata, sync state) stays in Atlassian’s infrastructure. It never changes your code. Details on the security page and in the privacy policy.

Questions before installing: support@linkwright.io.
